# Автобот новостей об авто и дорожных происшествиях в Таджикистане

Бот собирает русскоязычные новости из RSS, делает карусель из краткого пересказа, выкладывает её в Instagram через официальный API и сохраняет ссылку в журнал. Запуск выполняется GitHub Actions. Публикации и рекламное продвижение — разные действия: этот проект публикует обычные посты, рекламу не запускает.

## Как это устроено

1. По расписанию GitHub Actions читает RSS Asia-Plus, Avesta и Sputnik Таджикистан.
2. Фильтр выбирает материалы о машинах, дорогах, транспорте, ДТП и дорожных происшествиях в Таджикистане и убирает ссылки, уже записанные в журнал.
3. Gemini делает русскоязычный пересказ на 3–5 слайдов. Скрипт рисует JPEG-карусель с текстом и ссылкой на источник.
4. GitHub Pages размещает изображения по публичным HTTPS-ссылкам, откуда их забирает Instagram.
5. Бот публикует карусель в профессиональном Instagram-аккаунте через Instagram API with Instagram Login.
6. Успешные публикации записываются в `state/posted.json`.

Сначала настройте проект вручную и запустите workflow кнопкой **Run workflow**. Расписание включайте после проверки тестовой публикации. Рекламный бюджет не затрагивается.

## Настройка GitHub

1. Создайте на GitHub **публичный** репозиторий `instagram-agent` и загрузите сюда содержимое папки.
2. В настройках репозитория откройте **Pages** и выберите публикацию через **GitHub Actions**.
3. В **Settings → Secrets and variables → Actions → New repository secret** добавьте:
   - `GEMINI_API_KEY` — ключ Gemini API;
   - `INSTAGRAM_ACCESS_TOKEN` — токен профессионального Instagram-аккаунта;
   - `INSTAGRAM_USER_ID` — числовой ID этого аккаунта.
4. В **Settings → Actions → General → Workflow permissions** разрешите `Read and write permissions`, чтобы workflow мог сохранить журнал.
5. Для GitHub Actions отдельный ввод адреса Pages не нужен: workflow получает его после публикации сайта. Для локального запуска при желании укажите свой Pages URL в `config.json`.
6. Проверьте параметры аккаунта, API и источников в `config.json`.
7. Откройте **Actions → Instagram news bot → Run workflow**. Убедитесь, что пост корректно опубликован и ссылка появилась в `state/posted.json`.
8. После проверки расписание в `.github/workflows/publish.yml` будет запускать бота ежедневно. Расписание указано в UTC.

### Подготовка Instagram API

Аккаунт должен быть профессиональным (Creator или Business). Создайте приложение Meta с продуктом **Instagram API with Instagram Login**, пройдите вход через Instagram и получите пользовательский токен с разрешением `instagram_business_basic` и `instagram_business_content_publish`. Подставьте токен и ID аккаунта в GitHub Secrets. Не присылайте токены в чат и не сохраняйте их в файлах проекта.

Токены могут истекать или быть отозваны. GitHub Actions уведомит об ошибке в журнале запуска, но не может безопасно продлевать любой тип Instagram-токена автоматически. Перед включением расписания проверьте тип токена и настройте продление согласно инструкции Meta для вашего варианта входа.

## Ограничения и стоимость

- GitHub Actions и Pages доступны в бесплатном плане с ограничениями GitHub; для Pages требуется публичный репозиторий в бесплатном плане.
- Код и изображения каруселей в таком репозитории публичны. Секреты GitHub остаются скрытыми.
- Gemini API имеет бесплатные квоты, которые зависят от модели, региона и текущих условий. В проекте задана модель `gemini-3.8-flash`; при изменении доступности можно задать `GEMINI_MODEL` в GitHub Variables.
- Meta API публикует обычный контент. Платное продвижение требует отдельного рекламного бюджета и здесь не настраивается.
- RSS-ленты и бесплатные тарифы могут менять условия; при ошибке workflow остановится без публикации.

## Локальный запуск

Нужен Python 3.11+. Установите зависимости командой `python -m pip install -r requirements.txt`, установите переменные окружения и запустите `python run_bot.py --dry-run`. Режим `--dry-run` готовит изображения, но ничего не публикует.

Успешная публикация требует всех GitHub Secrets и доступного публичного URL на GitHub Pages. Никогда не включайте секреты в репозиторий.
